<summary><strong>About this portfolio’s source code</strong></summary>

This repository is the source for my portfolio. It uses Next.js, React, TypeScript, GSAP, Lenis, local assets, and a server-side contact flow. Content lives in `src/content/`; components and styles live in `src/components/` and `src/styles/`.

Run it with Node.js 22 or newer:

```bash
npm ci
npm run dev
```

For the automated checks, run `npm run check`. For a production Next.js build, run `npm run build`. The ChatGPT Sites build uses `npm run build:sites` and a Worker mail relay. See [hosting notes](docs/HOSTED_REVIEW.md) for the difference between the two deployments.

The contact form requires a separately configured server-side mail endpoint and SMTP credentials. Copy `.env.example` to `.env.local` for local configuration; never commit credentials. Direct email above remains the most reliable way to reach me.
